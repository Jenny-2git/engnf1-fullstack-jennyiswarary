# TriageSync – Ticket and Resource Management System

TriageSync is a full-stack web application . the two main task it solves are support ticket management and resource booking. and two types of user can log in as admin and as other multiple users.
when logged in as admin, he can mport, assign, categorize, and manage support tickets, monitor dashboard statistics, create resources, and approve or reject booking requests. Regular users can view and review their assigned tickets, browse available resources, book resources, and manage their bookings.

The frontend is developed using react and vite, while the backend uses node.js and express.js. postgresql is used for database management, and JWT authentication with role-based access control is implemented to secure the application.

The project focuses on simplifying ticket workflows, managing resource availability, preventing booking conflicts, and providing a centralized platform for administrators and users.
