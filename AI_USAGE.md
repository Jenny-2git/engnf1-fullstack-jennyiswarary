# AI Usage

I used ChatGPT during the development of this project mainly to understand concepts, solve errors, and get guidance whenever I faced difficulties.

I took help with:
- Understanding how React, Node.js, Express.js, and PostgreSQL work together.
- Fixing errors in the frontend and backend.
- Understanding API integration and JWT authentication.
- Improving ticket assignment and booking validation.
- Understanding the code and making the project documentation.

I did not rely on AI only to generate the project. I worked on the implementation myself, ran the application, tested its features, and fixed issues step by step with AI assistance.

AI was mainly used as a learning and debugging tool throughout the development process.
